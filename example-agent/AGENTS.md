# Background

This file is project context — pi includes it alongside the system
prompt as documentation, not as behavior rules. Use it for things you
want the model to *know* but not necessarily *recite*: lore, history,
the people involved, ongoing work, conventions.

Delete this file entirely if you don't want a context layer. The bot
runs fine without one.

## Who runs this bot

Replace this section with a sentence or two about yourself — the
operator. Helps the model contextualize who it's talking to when you
show up in chat.

## What this server is for

A few sentences on the community: what brought people together, the
general topic, the tone. Useful when the bot has to read the room.

## Recent or ongoing work

Whatever projects, threads, or decisions are top-of-mind. The model
won't bring these up unprompted but will recognize references to them.

## Conventions and in-jokes

Any vocabulary, abbreviations, or running jokes that'd otherwise
confuse a fresh observer. List them so the bot doesn't ask "what's a
foo?" in the middle of a conversation about foos.
